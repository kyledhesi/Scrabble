# Scrabble
A java based Scrabble game with two modes - Player vs Player & Player vs Computer

In order to run the application - download the ZIP and import it into a Java based IDE 

The application runs on Java JDK 11.0 10 / Java SE-11

To place a word - Select a tile and press the square you want to place the tile in 

Submit Button - Submit the word you want to place
Clear Button - Clear the tiles on the board for replacement 
Replace Tiles Button - Select the tiles you want to swap out and repress button to replace

AI Turn Button - Calls the AI to take its turn
